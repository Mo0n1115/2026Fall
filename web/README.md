# 틈 기능 시제품

저장소 루트에서 `python3 -m http.server 8080 --bind 127.0.0.1 --directory web`로 실행한다. 로컬 브라우저에서 해당 서버에 접속한다. API 키와 패키지 설치는 필요 없다. 클라우드에서 실행한 서버가 사용자 PC에 자동 공개되는 것은 아니다.

`node --test tests/routes.test.mjs`로 추천 로직을 검증한다.

## 응답 구조

`routes.mjs`의 `fixture`는 조사 기록을 참고한 합성 예시다. 실제 TMAP 응답을 캡처한 파일이나 전체 명세가 아니다.

- `metaData.plan.itineraries[]`: 경로 후보
- `totalTime`: 초 단위 총 시간
- `transferCount`: 환승 횟수
- `totalWalkDistance`: 미터 단위 도보 거리
- `legs[]`: 이동 구간. `mode`, `route`, `sectionTime`, `start`, `end`의 일부 필드만 사용

혼잡도 점수는 이 예시 응답에 포함하지 않고 별도로 결합한다. 같은 척도로 작성한 가상 값으로만 추천 순서를 검증한다. 실제 연동 시 데이터 출처·유형·기준 시각·지원 범위와 오류 상태를 추가해야 한다. `normalize`가 응답 구조를 내부 모델로 변환하고 `recommend`가 추가 시간 제한과 혼잡도·환승·도보 순 비교를 담당한다.

입력한 장소명은 표시용이며 실제 검색이나 길찾기를 하지 않는다. 예시 노선과 구간은 실제 이동에 사용하면 안 된다. 지도와 실제 승강장·출입구 정보, 자동 하차 알림·재탐색은 미구현이다.

위치 확인은 HTTPS 또는 브라우저가 보안 컨텍스트로 인정하는 로컬 환경과 권한이 필요하다. 좌표를 저장하거나 서버로 전송하지 않는다. 중단·안내 종료·도착·화면 숨김 시 감시를 해제한다. 모바일 잠금·백그라운드 지속 추적을 제공하지 않는다. 실제 기기의 GPS 검증은 별도로 필요하다.

## 지도 중심 버전

Leaflet 1.9.4와 OpenStreetMap 표준 타일을 사용한다. Leaflet은 npm 배포본의 SHA-512 무결성을 확인한 뒤 `vendor/`에 포함했으며 라이선스를 함께 배포한다. 지도 표시는 인터넷과 `tile.openstreetmap.org` 접속이 필요하다. 이 클라우드에서는 타일 요청이 프록시 403으로 차단되어 실제 타일 표시를 검증하지 못했다. 타일 요청에는 화면 영역이 지도 제공자에게 전달되며, 위치 좌표 자체를 앱 서버로 전송하거나 저장하지 않는다.

위치 권한 허용 후 GPS 마커와 정확도 원을 갱신한다. 지도를 끌면 따라가기가 해제되고 내 위치 버튼으로 복귀한다. 화면 숨김·추적 중단·안내 종료·도착 시 추적을 종료한다. 위치 갱신은 브라우저와 장치가 제공하는 빈도에 따르며 실제 기기 검증이 필요하다. 지도는 현재 실제 기능, 경로와 혼잡도는 예시다. 경로선·위치 매칭·자동 이탈 감지는 미구현이다.
