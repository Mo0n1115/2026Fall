# GitHub Pages 테스트 사이트

태블릿에서도 설치 없이 HTTPS 주소로 시제품을 열기 위한 배포 설정이다. 실제 API나 키는 포함하지 않는다. 배포되는 디렉터리는 `web/`뿐이며 조사 문서·테스트 파일은 사이트 산출물에서 제외한다.

## 최초 설정

1. 저장소의 Settings → Pages에서 Build and deployment의 Source를 **GitHub Actions**로 선택한다. 설정 권한이 필요하다.
2. 사용자 승인 후 `main`에 웹앱과 `.github/workflows/pages.yml`을 푸시한다.
3. Actions의 `Deploy Teum prototype to GitHub Pages` 실행에서 테스트·배포 성공을 확인한다.
4. `deploy` 작업에 반환된 실제 배포 주소를 연다. 실패한 실행을 게시 성공으로 취급하지 않는다.

예상 기본 주소는 `https://mo0n1115.github.io/2026Fall/`이다. 배포 전에는 접속 가능하다고 보장할 수 없으며 실제 주소는 성공한 배포 결과를 기준으로 안내한다. Pages 설정을 나중에 켰다면 Actions에서 이 워크플로를 수동 실행할 수 있다.

## 이후 변경

`main`에 `web/`, `tests/`, 배포 워크플로 변경을 푸시하면 테스트 후 재배포한다. 각 푸시 전에 사용자 승인을 받는다. 테스트는 실제 교통 API 연동 검증을 대신하지 않는다.

## 태블릿 확인

- HTTPS 사이트에서 지도 타일 표시·확대·이동 확인.
- 내 위치 버튼을 누르고 브라우저 위치 권한 허용.
- 현재 위치 마커·정확도와 이동에 따른 위치 갱신 확인.
- 지도 수동 이동 시 따라가기 해제, 내 위치 버튼으로 복귀 확인.
- 위치 거부·추적 중단·화면 전환 후 상태 확인.
- 경로 비교·수동 안내는 합성 예시임을 확인. 실제 길찾기나 자동 하차 안내는 미연동.

지도 타일은 OpenStreetMap 외부 서버에서 받는다. 클라우드에서 차단됐더라도 사용자 기기에서는 별도로 검증해야 한다. 공개 테스트 사이트에 정밀 위치를 저장하거나 키를 넣지 않는다. 공개 서비스 규모로 확장할 때는 지도 타일 제공 정책과 적절한 공급자를 재검토한다.
